Start with the marketer's real task

We treated creation and revision as the same job. A marketer could adapt an ad for a new message or format without losing the visual choices that made it part of the same campaign. Each revision kept the existing context instead of sending the user back to a blank canvas.

Shape the workflow through feedback

Customer feedback did not stop at a product brief. I worked with our product manager and designers to decide what should change, then built those changes into the interface. We tuned the path from a first draft to specific edits in the message, visual direction, and aspect ratio.

Connect the experience to agentic systems

The interface depended on the frontend, backend, async messaging, and AI/ML agents working as one product. I defined how those pieces exchanged state so users could see progress, keep their editing context, and understand where each generated result came from.

Own the path to production

I stayed hands-on in product design, interaction design, architecture, implementation, and launch. With fewer handoffs, customer feedback could turn into working software without the original intent getting diluted along the way.
