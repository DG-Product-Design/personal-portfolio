Marketplace discovery & checkout

Helping people find benefits that fit

Employees use Fringe points to buy products and services. I redesigned and rebuilt marketplace discovery and checkout so users could get from a relevant recommendation to checkout with fewer steps.

Find the friction before choosing a solution

I worked with design and product to run user tests and guided interviews. We learned what people came to the marketplace to find, where they got stuck, and how the cart contributed to the problem. We prototyped alternatives and ran A/B tests rather than assuming the first design was right.

Design for relevance and repeat behavior

We grouped recommendations around users' interests instead of showing everyone the same undifferentiated marketplace. Favorites and recurring purchases made it easier to return to products people already valued. A shorter checkout path and clearer cart removed decisions that were getting in the way.

Measure the journey in production

Production analytics showed an approximately 30% reduction in time from marketplace discovery to add-to-cart. The redesigned cart also increased completed checkouts. We did not call the work finished at launch; we kept measuring how people actually used it.

Build a foundation for faster experiments

To keep each experiment from becoming a one-off, I led the frontend architecture behind the product. We aligned a shared component library across Figma and Storybook, moved from JavaScript to TypeScript, Create React App to Vite, styled-components to Tailwind CSS, and upgraded React from 16 through 18. Development time dropped by approximately 40%, and later experiments were faster to build.
